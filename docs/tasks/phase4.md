# Phase 4: teams, roles, projects, status page

Decisions: [ADR-0102](../adr/0102-teams-roles-projects.md) (organizations, roles, invitations, projects), [ADR-0103](../adr/0103-status-page.md) (status page). Conventions as in [README.md](README.md): one commit per task, independent review after each task, ledger entries for shortcuts. Built and verified on the internal network in `klr-platform`.

**Phase 3 agent tasks are postponed.** A-01..A-04, V-01 and K-01 in [phase3.md](phase3.md) start after this phase. After T-02, agents belong to a project (`project_id` on agents and their monitors, created by admins or members of that project); A-01 is updated before it starts.
